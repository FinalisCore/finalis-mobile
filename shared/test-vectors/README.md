# Test Vectors

This directory indexes shared fixtures used by Android to keep wallet behavior aligned.

V1 vectors cover:
- address handling
- transaction handling
- finalized history rendering inputs
- lightserver response examples and wallet derivation fixtures
- `tx/sighash-v4-testnet.json`: chain domain, spent-outputs hash, per-input `SC-SIG-V4` sighash and signed tx generated by finalis-core (see `shared/tooling/core-vectors/`)
